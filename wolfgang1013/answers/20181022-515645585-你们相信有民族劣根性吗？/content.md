# 你们相信有民族劣根性吗？

**作者**：[陈子敏](http://www.zhihu.com/people/91949509989e39acc6e55e4216ac260b)

**原文**：https://www.zhihu.com/question/299242672/answer/515645585

**发布时间**：2018-10-22T03:01:39

赞同 7 · 收藏 0 · 喜欢 0 · 评论 0

不相信。

不同民族间，不同风俗习惯、不同发展程度的差异是显而易见的。

发展程度较低的民族当然会给人以恶劣印象，但所谓“劣根性”只是种族主义者实践自己偏见的托辞而已。
