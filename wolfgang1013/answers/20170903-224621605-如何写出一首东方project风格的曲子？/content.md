# 如何写出一首东方project风格的曲子？

（在一小段落范围内的）只用三和弦不断半音离调，产生一种非功能的诡异风格，最著名的如《U.N》、《人形裁判》、《ブクレシュティの人形師》、《狂気之瞳》、《ハルトマンの妖怪少女》等其中出现的固定音型与动机；

贯彻始终的IV-V-VI级和声进行，例子过多不予穷举；

频繁的356，612的和风动机开头，（通常前二个音出现在弱起）如《竹取飞翔》、《千年幻想乡》、《飘上月球，不死之烟》、《神々が恋した幻想郷》；

旋律大多为带变宫的六声羽调式，或自然调式缺IV级，也有太多例子。

配器上楼上已经指出过，ZUN喜欢用钢琴奏出伴衬旋律的华彩性音型织体；当然还有人间最美的乐器ZUN号（Roland SD-90），常用于陈述主题；

ZUN喜欢用哪种合成器和电鼓暂不清楚，有待知情者补充。
